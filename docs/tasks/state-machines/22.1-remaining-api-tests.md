## Implementation

### 1. Cancel Running Instance (§11)

**What exists:** The `slowDefinitionBody` fixture (uses the `delay` action with a long `durationMs`) is already defined. The `postCancel` helper is already defined.

**What to add:** A test in the `Cancel` describe block:

```typescript
it('POST cancel on running instance → 200', async () => {
  const defId = await createDefinition(slowDefinitionBody);
  const instance = await startInstance(defId, {
    durationMs: 5000,
    nextState: 'completed',
  });

  // Wait for the runner fiber to start executing
  await new Promise((r) => setTimeout(r, 100));

  // Verify it's running
  const getRes = await getInstance(instance.id);
  const inst = (await getRes.json()) as { status: string };
  expect(inst.status).toBe('running');

  // Cancel it
  const cancelRes = await postCancel(instance.id);
  expect(cancelRes.status).toBe(200);

  // Wait for the fiber interruption finalizer to persist
  await new Promise((r) => setTimeout(r, 200));

  // Verify the instance is now cancelled
  const afterRes = await getInstance(instance.id);
  const afterBody = (await afterRes.json()) as { status: string };
  expect(afterBody.status).toBe('cancelled');
});
```

**Key details:**

- `delay` action with `durationMs: 5000` keeps the machine in `running` for ~5 seconds
- 100ms delay before cancel lets the runner fiber start executing
- `runner.cancel()` returns `Effect<void, NotFoundError | DefinitionError>` — route maps success to 200 with `{ message: 'Instance cancelled' }`
- After cancel, the `Effect.onInterrupt` finalizer sets status to `'cancelled'` and persists — allow ~200ms for that to complete

### 2. Artifact Download (§15)

There is no built-in `save-artifact` action. The test must register a custom action in the test harness that calls `ctx.artifacts.write()`.

**Step 2a: Register a custom `save-artifact` action**

After building the `ManagedRuntime` in `makeHandler()`, access the `ActionRegistry` from the runtime to register a test-only action:

```typescript
import { ActionRegistry } from '@/machines/ActionRegistry.js';

async function makeHandler() {
  const managedRuntime = ManagedRuntime.make(TestLayer);
  const runtime = await managedRuntime.runtime();

  // Register a test-only action that writes an artifact
  await managedRuntime.runPromise(
    Effect.gen(function* () {
      const registry = yield* ActionRegistry;
      yield* registry.register(
        'save-artifact',
        (ctx) =>
          Effect.gen(function* () {
            const content = ctx.stateData as {
              filename?: string;
              content?: string;
              nextState?: string;
            };
            const filename = content.filename ?? 'output.txt';
            const fileContent = content.content ?? 'hello from artifact';
            const nextState = content.nextState ?? 'completed';

            yield* ctx.artifacts.write(filename, new TextEncoder().encode(fileContent));
            yield* ctx.logger.info(`Wrote artifact: ${filename}`);

            return { nextState, data: { artifact: filename } };
          }),
        { name: 'save-artifact', description: 'Test action that writes an artifact file' },
      );
    }),
  );

  const served = MachineRouter.pipe(HttpRouter.use((httpApp) => Effect.provide(httpApp, runtime)));
  return HttpApp.toWebHandler(served);
}
```

**Step 2c: Add the download test**

Add a test in the `Artifacts` describe block:

```typescript
it('GET /instances/:id/artifacts/:name downloads file content', async () => {
  const defId = await createDefinition(artifactDefinitionBody);
  const instance = await startInstance(defId, {
    filename: 'report.txt',
    content: 'artifact content here',
    nextState: 'completed',
  });

  // Wait for machine to complete and artifact to be written
  await new Promise((r) => setTimeout(r, 300));

  // Verify the instance completed
  const instRes = await getInstance(instance.id);
  const instBody = (await instRes.json()) as { status: string };
  expect(instBody.status).toBe('completed');

  // List artifacts — should include our file
  const listRes = await getArtifacts(instance.id);
  expect(listRes.status).toBe(200);
  const artifacts = (await listRes.json()) as { name: string }[];
  expect(artifacts.some((a) => a.name === 'report.txt')).toBe(true);

  // Download the artifact
  const downloadRes = await getArtifact(instance.id, 'report.txt');
  expect(downloadRes.status).toBe(200);

  const body = await downloadRes.text();
  expect(body).toBe('artifact content here');
});
```

**Key details:**

- The route reads the artifact via `ArtifactStoreFactory.makeScoped()` → `store.read(name)` which returns a `Uint8Array`
- The response uses `HttpServerResponse.uint8Array(content, { headers: { 'content-type': artifact.contentType } })`
- `FsArtifactStoreLive` writes to `<ARTIFACT_ROOT>/<instanceId>/` — in tests this uses the default `./data/artifacts`
- The `TextEncoder`/`TextDecoder` round-trip preserves the text content
